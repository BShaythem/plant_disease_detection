# Olive Care - Sample Leaf Dataset

This folder stores high-resolution reference olive leaf images for mock detections and demonstrations:

| File | Pathology Condition | Scientific Name | Key Visual Diagnostic Features |
|---|---|---|---|
| sample1.jpg | Olive Peacock Spot | *Spilocaea oleagina* | Concentric circular dark spots with yellowish halo on upper leaf blade |
| sample2.jpg | Olive Knot Disease | *Pseudomonas savastanoi* | Rough knobby galls on leaf petiole and twig junctions |
| sample3.jpg | Verticillium Wilt | *Verticillium dahliae* | Sectoral leaf curling, greyish-green desiccation and wilt |
| sample4.jpg | Olive Anthracnose | *Colletotrichum gloeosporioides* | Brown marginal necrosis and chlorotic halo on foliage |
| sample5.jpg | Olive Leaf Chlorosis | Nutritional / Fe-Mg deficiency | Interveinal yellowing with preserved green main vein |
| sample6.jpg | Healthy Olive Foliage | *Olea europaea* | Vibrant silver-green waxy cuticle with no pathogen lesions |

### Customizing Sample Images:
You can replace any sample[1-6].jpg file with your own orchard photographs (recommended size: 800x600 or larger JPG/PNG). The app loads these files directly into the History and Scanner modules.
